# Contador em JavaScript

**Estudo em desenvolvimento · HTML · CSS · JavaScript**

Estrutura inicial de um exercício de contador, com valor na tela e botões para iniciar e parar a contagem.

## Estado atual

O HTML está presente, mas os arquivos `assets/js/scripts.js` e `assets/css/styles.css` estão vazios. As funções `ComecarContar()` e `PararContar()`, chamadas pelos botões, ainda não estão implementadas.

## Como visualizar a estrutura

```bash
git clone https://github.com/marcosmaldonadoo/counter-in-javascript.git
cd counter-in-javascript
```

Use um servidor local na raiz do repositório, como o Live Server do VS Code, pois o HTML referencia os arquivos de `assets` com caminhos iniciados por `/`.

## Estrutura

```text
index.html
assets/
├── css/styles.css
├── img/jslogo.png
└── js/scripts.js
```
